# CS4347 Project Phase4

## Development

For any contributions, make your own branch that contains your first name in the branch name.

## Running the project

To run the project, you must have MySQL (server & workbench) and PHP installed. Make sure that the database is ready by running the `create.sql` and `load.sql` scripts in MySQL if you haven't already done so. Start the PHP development server by running the command below in your terminal **in the repository folder**:

```
php -S localhost:8000
```
